## ⚡ En Construcción & Proyectos Activos

Sistemas en desarrollo activo centrados en lógica de negocio estricta, concurrencia y control de acceso.

---

### 🛡️ Gestor Documental Institucional (DMS)
> *Sistema de gestión de archivos diseñado para entornos educativos con alta sensibilidad de datos.*

- **Control de Acceso Granular (RBAC):** Separación estricta de permisos e identidades por roles (alumnado, profesorado, dirección) y mitigación de fugas mediante identificadores únicos.
- **Flujo y Trazabilidad:** Control de ciclo de vida documental mediante máquina de estados (`Borrador` ➔ `En revisión` ➔ `Aprobado` ➔ `Firmado`).
- **Seguridad en Almacenamiento:** Auditoría de cambios y desacoplamiento estructural entre ficheros físicos en servidor, lógica de consulta y base de datos.
- **Stack:** `Java` `PostgreSQL` `Docker` `Seguridad Defensiva`

---

### 🔄 Plataforma de Gestión & Membresías
> *Arquitectura orientada a lógica de negocio, combinando principios de CRM vertical y ERP operativo.*

- **Ciclo de Vida y Conversión (Lógica CRM):** Pipeline automatizado de usuario (`Solicitud inicial` ➔ `Validación` ➔ `Checkout` ➔ `Onboarding` ➔ `Fidelización`). Sincronización en tiempo real consumiendo APIs REST externas (OAuth2 y Bots).
- **Operativa y Recursos (Lógica ERP):** Gestión de cupos limitados con control estricto de concurrencia en base de datos.
- **Automatización de Suscripciones:** Máquina de estados para cobros recurrentes y expiración automática con liberación inmediata de plazas.
- **Stack:** `PHP` `Docker` `MariaDB` `OAuth2` `REST APIs Seguras`
